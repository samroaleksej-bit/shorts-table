# Шортсы к релизу

Общая таблица шортсов команды: кто автор, какой файл, название, описание, превью, дата релиза.
Сайт - одна страница на GitHub Pages, данные лежат в Supabase, новые ролики раз в час подтягиваются с Яндекс Диска.

## Что где

- `index.html` - сама страница.
- `config.js` - адрес базы и публичный ключ.
- `seed.json` - 71 ролик из старой xlsx-таблицы, для разового переноса кнопкой на странице.
- `supabase/setup.sql` - создание таблицы и правил доступа.
- `sync/sync.mjs` и `.github/workflows/sync.yml` - часовая синхронизация с Яндекс Диском.

## Подключение базы (один раз)

1. В Supabase создать проект.
2. SQL Editor - вставить содержимое `supabase/setup.sql` - Run.
3. Authentication - Users - Add user: почта `team@shorts.local`, пароль - общий пароль команды, галочка Auto Confirm User.
4. Authentication - Sign In / Providers: выключить «Allow new users to sign up», чтобы посторонние не могли завести себе пользователя.
5. Project Settings - API: скопировать Project URL и публичный ключ (anon / publishable) в `config.js`.

Секретный ключ (service_role / secret) в файлы репозитория не класть.

## Синхронизация с Яндекс Диском

В настройках репозитория, Settings - Secrets and variables - Actions:

Секреты:
- `SUPABASE_URL` - адрес проекта.
- `SUPABASE_SERVICE_KEY` - секретный ключ.
- `YADISK_SOURCES` - публичные ссылки на папки, по одной в строке. Если по пути к файлу не понять автора, его можно указать: `https://disk.yandex.ru/d/xxxx = Лера`.

Переменная:
- `SYNC_ENABLED` = `true` - включает запуск по расписанию. Пока её нет, по расписанию ничего не происходит.

Скрипт берёт видео из каталогов «ПРИНЯТО К РЕЛИЗУ» и добавляет строку с автором и именем файла.
Если ролик с таким именем уже есть в таблице, он не дублируется, а привязывается к файлу.
Скрипт ничего не удаляет и не трогает заполненные поля.

Первый раз запускать вручную в пробном режиме: Actions - «Синхронизация с Яндекс Диском» - Run workflow, галочка dry_run включена. В журнале будет список того, что добавилось бы.

GitHub сам отключает расписание, если в репозитории 60 дней не было коммитов - тогда включить заново во вкладке Actions.

## Как устроен доступ

Страница открыта по ссылке, но данные видны только после ввода общего пароля команды. Пароль вводится один раз на устройство.
Удаление в таблице мягкое: строка скрывается, но остаётся в базе, поэтому синхронизация не вернёт её обратно.
